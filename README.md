# 记账助手 · 微信/支付宝账单分析

一个离线可用的记账 Web App（PWA）：导入微信 / 支付宝官方账单文件，自动解析、自动分类，输出量化表格、图表、消费分析与"该怎么花"的建议。

> 数据**只保存在你本机的浏览器**（localStorage），不会上传到任何服务器。

---

## 一、怎么拿到账单文件

### 微信支付账单（导出 CSV）
1. 微信 → 我 → 服务 → 钱包 → 账单
2. 右上角「···」→「下载账单」→ 选择「用于个人对账」
3. 选时间范围 → 填写接收邮箱 → 确认
4. 到邮箱下载附件（`微信支付账单明细.csv`，解压后得到 CSV）

### 支付宝账单（导出 CSV 或 Excel）
1. 支付宝 → 我的 → 账单 → 右上角「···」
2. 「开具交易流水证明」或「下载账单」
3. 选时间范围 → 填邮箱 → 下载附件（`alipay_record_xxx.csv` / `.xlsx`）

> 两个平台都能导出 CSV，**首选 CSV**（无需联网即可解析）；支付宝的 Excel（.xlsx）也支持，但首次解析需联网加载一个库。

## 二、怎么使用

- **电脑上**：直接双击打开 `index.html` 即可（CSV 完全可用；xlsx 需联网）。
- **iPhone 上（推荐，做成 App 图标）**：需要先把这套文件托管到一个网址（见下），再用 Safari 打开 → 分享按钮 → 「添加到主屏幕」，即可生成带图标的独立 App，离线可用。

### 方式 A：同 WiFi 局域网访问（临时测试）
在项目目录下起一个静态服务（见下方命令），在电脑上查到自己局域网 IP，iPhone 连同一 WiFi 后，在 Safari 打开 `http://<电脑IP>:8000`。

```bash
# 项目目录下，任选其一
python -m http.server 8000
# 或 npx serve -l 8000
```

### 方式 B：免费部署到公网（永久、随时可用）
把整个文件夹上传到任意静态托管即可，例如：
- **GitHub Pages**：新建仓库 → 上传 `index.html`、`manifest.webmanifest`、`sw.js`、`icons/` → 仓库 Settings → Pages 开启。
- **Vercel / Netlify**：直接拖拽项目文件夹到网站即可生成网址。

得到网址后，iPhone Safari 打开 → 分享 → 「添加到主屏幕」。

## 三、功能说明

| 模块 | 内容 |
|------|------|
| 总览 | 收入/支出/结余/储蓄率 + 月度收支趋势 + 支出分类占比 + 商户支出 TOP10 |
| 分类 | 按「居住/通讯/医疗/教育/交通/餐饮/娱乐/购物/红包转账/资金往来」统计笔数与金额 |
| 明细 | 支持时间范围、收支方向、关键字搜索，最多展示 300 条 |
| 建议 | 储蓄率、餐饮/购物/娱乐占比、订阅续费、大额单笔、信用卡还款等规则化提示 |
| 预算 | 月总预算 + 各分类预算，超支自动标红提示 |
| 截图识别 | 上传账单截图，自动 OCR 识别交易（首次需联网下载模型） |
| 自定义分类 | 自定义关键词 → 分类规则，自动归类 |
| 同步 / 备份 | 「🔄 同步」合并 `ledger.json`；「⬇ 导出」一键备份为 JSON |

- 支持**重复导入去重**（按 时间+金额+对方+方向 判断）。
- 支持**多文件批量导入**、**清空数据**、**示例数据**演示。
- 「资金往来」（充值/提现/理财/还款）不计入收支，单独统计。

## 四、关于"自动记账"的说明

苹果 iOS 沙盒不允许 App 读取微信/支付宝内部数据，两个平台也不开放交易流水接口，因此**没有任何 App 能做到真正的全自动抓取**。本应用采用业内通用做法：导入官方账单导出文件后**自动解析 + 自动分类 + 自动出表出建议**，这是合规且最接近"自动"的方案。

本应用现已内置「截图识别」：上传微信/支付宝账单截图，自动 OCR 提取金额、日期、商户（结果可逐笔核对修改后导入）。首次使用需联网下载中文识别模型。

更进一步的"自动"：见下方「自动记账脚本」，把导出的账单文件放进指定文件夹即可自动解析入库。

## 五、自动记账脚本（放文件夹自动入账）

配套脚本 `auto_import.py`：把微信/支付宝导出的账单文件放进 `bills/` 文件夹，脚本自动解析、去重、合并成 `ledger.json`，应用里的「🔄 同步」按钮（或刷新页面）自动入库，形成"导出账单 → 丢进文件夹 → 自动记账"的闭环。

```bash
# 在项目目录下，用 Python 运行
python auto_import.py             # 增量处理 bills/ 里新增/变动的文件
python auto_import.py --force     # 全量重建（删除账单文件后重算用）
python auto_import.py --watch     # 持续监听 bills/（每 5 秒扫一次，Ctrl+C 停止）
```

> 脚本只解析原始流水，分类与去重由应用在同步时统一处理，所以自定义分类、预算等设置对导入的数据同样生效。已处理过的文件会记录在 `bills/.processed.json`，重复运行不会重复计入。

- 「⬇ 导出」按钮可随时把全部数据备份成 JSON；「🔄 同步」按钮把 `ledger.json` 合并进本机数据（自动去重）。
- 想完全自动化，可在 Windows「任务计划程序」里加一个定时任务，每天运行一次 `python auto_import.py`（配合邮箱自动下载账单附件，即每天自动更新）。
